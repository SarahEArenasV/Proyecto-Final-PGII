------------------

## 📌 Descripción
Proyecto final de **Programación II** – Universidad del Quindío.

CinemaUQ permite gestionar la cartelera, las funciones, las salas y la confitería de un cine.
También maneja la venta de entradas con tarjeta recargable, el programa de puntos, los reembolsos y los reportes administrativos.
