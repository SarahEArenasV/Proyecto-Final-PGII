# CinemaUQ — Sistema Integral de Gestión de Cine

Proyecto final del curso Programación II (PGII) — Universidad del Quindío.

Aplicación de escritorio en Java/JavaFX para la gestión integral de un cine: cartelera,
funciones, venta de entradas, productos de confitería, tarjeta virtual, puntos CinemaUQ
y reportes administrativos.
